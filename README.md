# MMDirect Encoder

MMD v9.32向けのDirectShow動画エンコーダーです。

## ダウンロード

[Release](https://github.com/hatoghx/MMDirectEncoder/releases)

## 対応環境

Windows 64bit(x64)

## インストール

ZIPを展開し、`install.exe`を実行してください。

## 設定

`MMDirectEncoderConfig.exe`を起動してください。
